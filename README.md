# Little Taco Shop

A responsive React website built with Vite, with separate pages for the menu, story, opening hours, and contact details.

## Start locally

1. Install [Node.js](https://nodejs.org/) if it is not already installed.
2. In this folder, run `npm install`.
3. Run `npm run dev` and open the local URL printed in the terminal.

## Production build

Run `npm run build` to create the deployable site in `dist/`. Use `npm run preview` to preview that build locally.

The contact form is currently a front-end demo and does not deliver messages; use the listed phone number to contact the shop.
